# DiamondML
Diamond Price Prediction
This repository demonstrates the application of regression trees and random forests to predict diamond prices using a publicly available dataset. The workflow involves comprehensive data preprocessing, exploratory data analysis (EDA), and model evaluation to ensure robust predictions. Key steps include:

Dataset Preparation:

Split the dataset into training (70%) and testing (30%) sets.
Analyze both splits to assess performance.
Exploratory Data Analysis (EDA):

Plot and analyze the correlation matrix of the dataset.
Visualize and interpret the distribution of each feature.
Data Preprocessing:

Apply scaling and normalization.
Perform label encoding and one-hot encoding where appropriate.
Conduct feature selection to optimize model input.
Remove duplicate entries to clean the dataset.
Random Forest Regression:

Train a random forest regression model on the training dataset.
